--- layout: default --- {%- comment -%} Same viewer as /photography/ — slide and grid modes off one shared include, and the same masonry grid, so a postcard stays 4 × 6 and a square mark stays square instead of every piece being cropped to one shape. Order comes from _data/design_order.yml (newest first, generated by bin/generate-photo-order.py). Anything on disk but missing from that list is appended, so a stale order file never hides work. {%- endcomment -%} {%- assign design_files = site.static_files | where_exp: "f", "f.path contains '/assets/images/design/'" -%} {%- assign order = site.data.design_order -%} {%- comment -%} A cycling tile is one entry in the grid with several files behind it, named in _data/design_cycle.yml. Only the first is listed; the rest are collected here so the loop can pass them over, and handed to the viewer as "c" so the page can change them on a timer. {%- endcomment -%} {%- assign cycle_extra = "" | split: "" -%} {%- for pair in site.data.design_cycle -%} {%- for extra in pair[1] -%} {%- assign cycle_extra = cycle_extra | push: extra -%} {%- endfor -%} {%- endfor -%} {%- assign ordered_names = "" | split: "" -%} {%- for name in order -%} {%- if cycle_extra contains name -%}{%- continue -%}{%- endif -%} {%- assign want = "/assets/images/design/" | append: name -%} {%- for f in design_files -%} {%- if f.path == want -%} {%- assign ordered_names = ordered_names | push: name -%} {%- endif -%} {%- endfor -%} {%- endfor -%} {%- for f in design_files -%} {%- assign fname = f.path | split: '/' | last -%} {%- if cycle_extra contains fname -%}{%- continue -%}{%- endif -%} {%- unless ordered_names contains fname -%} {%- assign ordered_names = ordered_names | push: fname -%} {%- endunless -%} {%- endfor -%} {% include viewer.html base="/assets/images/design/" masonry=true %}
